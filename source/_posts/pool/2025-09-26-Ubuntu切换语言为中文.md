可怜的孩纸一直在用英文系统，偶然才发现别人的怎么是中文，我也想要！

~~（其实用英文也非常不错，可以创造英文环境学习英语，换完有点后悔了，但换了再说）~~

```bash
# 1. 安装中文语言包
sudo apt update
sudo apt install language-pack-zh-hans

# 2. 设置系统语言
sudo dpkg-reconfigure locales
# 选择 zh_CN.UTF-8

# 3. 设置默认语言环境
sudo locale-gen zh_CN.UTF-8
sudo update-locale LANG=zh_CN.UTF-8

# 4. 重启系统或重新登录
reboot
```
